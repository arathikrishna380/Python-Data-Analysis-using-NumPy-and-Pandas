# Python Data Analysis Assignment - using NumPy and Pandas
This repository contains solutions and code implementations for an introductory Data Analysis assignment focusing on **NumPy** and **Pandas** in Python.

## 📁 Assignment Overview
The assignment is divided into three major modules covering fundamental numerical computations, data structures, and exploratory data analysis:

1. **NumPy Array Operations & 2D Arrays:** Creating arrays, data type inspection, shape verification, Fahrenheit conversion, mathematical statistics (max, min, mean), and advanced array slicing/indexing.

2. **Pandas Series:** Creating custom-indexed Series, positional vs. label-based indexing (`loc` and `iloc`), boolean filtering, element updates, dropping rows, and vectorized mathematical operations.

3. **Pandas DataFrame:** Constructing multi-column dataframes, data exploration (`head`, `tail`, `shape`, `dtypes`), column selection, conditional filtering, categorical value counts, unique identification, grouping, and DataFrame manipulations.

## 🛠️ Technologies Used

* **NumPy**
